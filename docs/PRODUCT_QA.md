# Reward Goblin product QA checklist

- [ ] Test the first-time user experience with a clean profile.
- [ ] Verify rewards cannot be claimed twice through repeated requests.
- [ ] Check persistence after refresh and interrupted sessions.
- [ ] Test empty, invalid, and unusually large inputs.
- [ ] Ensure feedback and progress indicators reflect actual saved state.
- [ ] Confirm keyboard and mobile usability.
- [ ] Document known limitations before publishing a demo.

Treat these as planned verification cases, not as claims of completed testing.
